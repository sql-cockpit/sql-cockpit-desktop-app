## Overview

Initial **release integration test** for SQL Cockpit App. This is a placeholder test build, **not production-ready**. Windows and Mac share version **0.0.1**.

## Added

- Minimal Electron, React and TypeScript desktop shell.
- Placeholder dashboard displaying the installed application version.
- Shared release history with separate installers for each platform and architecture.
- GitHub Actions packaging and release publication after all installer builds succeed.

## Windows

- Windows x64 NSIS `.exe` installer with an installation-directory choice.
- **Unsigned test build**: no Windows signing certificate is configured. Windows may display security warnings.

## macOS

- Separate `.dmg` installers for **Apple Silicon (arm64)** and **Intel (x64)**.
- **Ad-hoc signed for packaging only**, not signed with an Apple Developer ID and **not notarized**. macOS may prevent normal opening of the test build.

## Known limitations

- **This placeholder does not connect to databases.**
- No account login, production workflows, in-app updater or migration functionality.
- Installers are intended solely for release-feed and changelog testing, not production use.
- Platform builds use Electron's default application icon until final branding is supplied.
- Signing and notarization require a separately configured production release workflow and genuine credentials.
