## Overview

**Release integration test — not production-ready.** Linux joins Windows and Mac in the shared **0.0.2** Electron desktop release. Version 0.0.1 remains available in release history.

## Added

- Linux x64 AppImage download and Ubuntu-hosted build/smoke validation.
- Linux platform details in the placeholder screen and documentation.
- All four installers are required before publication; checksums include Linux.
- Website release-feed compatibility for the Linux AppImage asset.

## Windows

- Windows x64 NSIS `.exe` installer, rebuilt from the shared 0.0.2 package.
- **Unsigned test build**; no signing certificate is configured.

## macOS

- Apple Silicon (arm64) and Intel (x64) `.dmg` installers.
- Ad-hoc signed for packaging only; **no Developer ID signing or notarization**.

## Linux

- **x64 AppImage**: `SQL-Cockpit-App-0.0.2-linux-x86_64.AppImage`.
- Mark the downloaded file executable before running it on a compatible Linux desktop.
- Some distributions require FUSE support. No Linux ARM build is provided yet.
- **Unsigned test build**, with published SHA-256 checksums.

## Known limitations

- **This placeholder does not connect to databases.**
- No production functionality, login or automatic updates.
- Installers are for release and changelog testing only. Windows/macOS may display security warnings or block normal opening.
- Uses the default Electron application icon pending final branding.
